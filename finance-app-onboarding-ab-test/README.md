\# Финтех-приложение для онлайн-торговли финансовыми активами



> Исследование влияния обучающего онбординга на поведение пользователей финтех‑приложения SollmaFin. Эксперимент подтвердил: углублённое обучение не снижает конверсию в первый депозит и значимо повышает повторные пополнения, но формирует полярное поведение пользователей — осторожные снижают суммы вложений, вовлечённые — увеличивают. Рекомендована гибкая система онбординга (быстрый старт / глубокое погружение).





\## Задача



Оценить эффект обновлённого онбординга с информацией об активах и рисках на инвестиционную активность новых пользователей SollmaFin (начинающие инвесторы на рынке Латинской Америки: Мексика, Бразилия, Колумбия, Аргентина).



Ключевая проблема: из‑за низкой финансовой грамотности пользователи выбирают высокорисковые активы, теряют деньги и уходят. Новый онбординг должен повысить осознанность, но есть риск отпугнуть новичков избыточной информацией.



Цель анализа — определить, как обучение влияет на бизнес‑метрики, выявить сегменты с разной реакцией и сформулировать рекомендации по UX и монетизации.





\## Данные



\-   \*\*Период эксперимента:\*\* две недели (новые пользователи).

\-   \*\*Группы:\*\*

&#x20;   -   контрольная — стандартный онбординг;

&#x20;   -   тестовая — онбординг с обучением по рискам и активам.

\-   \*\*Наблюдение:\*\* активность пользователей в течение недели после регистрации.

\-   \*\*Метрики:\*\*

&#x20;   -   \*\*ключевая\*\* — средняя сумма всех депозитов на пользователя;

&#x20;   -   \*\*барьерная\*\* — конверсия из регистрации в первый депозит;

&#x20;   -   \*\*вспомогательные:\*\*

&#x20;       -   конверсия из первого депозита во второй;

&#x20;       -   средняя сумма депозитов на платящего пользователя.





\## Подготовка данных



\-   Проверка пропусков, дубликатов, валидность идентификаторов пользователей.

\-   Корректное сопоставление пользователей с группой (контроль / тест) и периодом эксперимента.

\-   Очистка аномальных значений сумм депозитов.

\-   Формирование признаков: статус платящего, количество депозитов, суммы, длительность сессии в онбординге.



\## Результаты



\-   Конверсия из первого депозита во второй в тестовой группе выросла на \*\*83 %\*\* (статистически значимо).

\-   Конверсия из регистрации в первый депозит \*\*не снизилась\*\*.

\-   Средняя сумма всех депозитов на пользователя показала незначимый рост на \*\*1.37 %\*\*.

\-   Средняя сумма депозита для платящего пользователя выросла на \*\*2.73 %\*\* (незначимо).

\-   Бутстрап‑анализ перцентилей выявил полярное поведение:

&#x20;   -   «осторожные» пользователи снизили суммы депозитов;

&#x20;   -   «вовлечённые» — значительно увеличили.  

&#x20;       Это сбалансировало ключевую метрику.

\-   На этапе завершения онбординга конверсия в тестовой группе ниже, чем в контрольной.



Критерий успеха эксперимента достигнут: барьерная и ключевая метрики не упали, одна из вспомогательных показала значимый рост.







\## Рекомендации



1\.  \*\*Внедрить гибкую систему онбординга:\*\* дать пользователю выбор между «быстрым стартом» и «глубоким погружением». Это поможет сохранить лояльность осторожных пользователей и усилить вовлечённость активных инвесторов.

2\.  \*\*Детально изучить этап завершения онбординга\*\* — там наблюдается снижение конверсии в тестовой группе.

3\.  \*\*Проанализировать эффект фичи по географическим срезам\*\* (по странам) для более точной настройки онбординга.

# Исследование рынка стартапов
 
> Проведён анализ 40 747 стартапов для оценки инвестиционной модели «покупка → развитие → перепродажа». Что сделано: подготовлен и очищен датасет (проверка пропусков/дубликатов,валидация ключей), выполнен разведочный анализ финансирования, сделок и раундов. Ключевые результаты: медиана точнее среднего отражает типичный объём финансирования; число раундов коррелирует со статусом компании (у `ipo` и `closed` — больше раундов, у `acquired` — меньше); отраслевая категория слабо предсказывает успех; выявлено 1 615 сделок с нулевой стоимостью (чаще в `software`, `web`, `enterprise`, `biotech`).
 
## Задача
 
Финансовая компания рассматривает выход на рынок инвестиций в стартапы. Нужно подготовить корректный датасет и исследовать исторические данные о компаниях, финансировании и сделках приобретения, чтобы выделить признаки для оценки стартапов.
 
## Данные
 
**Объём:** 40 747 компаний (привлекали финансирование или были приобретены).
**Качество:** около 50% сотрудников не имеют данных об образовании.
 
## Подготовка данных
 
- Проверка пропусков, дубликатов, уникальности идентификаторов.
- Определение ключей для объединения таблиц.
- Разделение смешанной таблицы на отдельные сущности «компании» и «раунды».
 
## Результаты
 
- **Финансирование.** Распределение  сильно скошено вправо. Медиана — 0.6 млн рублей; для компаний с ненулевым финансированием — 2.56 млн рублей. Среднее — около 10 млн рублей (искажено выбросами).
- **Сделки за 0.** 1 615 компаний (около 4% приобретённых) куплены за ноль при наличии финансирования. Чаще встречаются в категориях `software`, `web`, `enterprise`, `biotech`.
- **Категории с более высокими медианными ценами** (при большом разбросе): `biotech`, `cleantech`, `ecommerce`, `security`, `public-relations`. Для надёжности учитывались только категории с ≥30 компаниями.
- **Раунды финансирования.** Медиана у большинства стартапов — 0. Среднее число раундов по статусам:
 
| Статус | Среднее число раундов |
| :--- | :---: |
| `closed` | 1,12 |
| `ipo` | 1,09 |
| `acquired` | 0,52 |
| `operating` | 0,24 |
 
Компании со статусами `ipo` и `closed` в среднем проходили больше раундов; приобретённые компании чаще покупались на ранних стадиях.

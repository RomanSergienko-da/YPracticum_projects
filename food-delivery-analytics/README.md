# Сервис доставки еды



> Анализ данных сервиса доставки еды: выявлены точки роста для повышения удержания пользователей и улучшения работы с ресторанами-партнёрами. Главный инсайт — конверсия на этапе подтверждения телефона в мобильном приложении всего 55% против 90% на десктопе; почти 70% пользователей совершают только одну покупку; рестораны были разделены на четыре кластера с разными моделями работы.



## Задача



Нужно найти инсайты, которые позволят повысить удержание пользователей и улучшить взаимодействие с партнёрами-ресторанами.



Вопросы бизнеса:

- Как ведут себя пользователи? Как выстроить работу, чтобы они продолжали пользоваться продуктом?

- Какой путь проходят пользователи в сервисе? Где «проваливаются»?

- Как улучшить взаимодействие с партнёрами-ресторанами?





## План проекта



- Загрузка данных и предобработка

- Анализ пользовательского пути новых пользователей

- RFM-сегментация

- K-Means кластеризация ресторанов

- Итоговый вывод и рекомендации



## Результаты



**Воронка пользователей.** Пользователи теряются на этапе подтверждения телефона в мобильном приложении — конверсия 55% против 90% на десктопе. При этом те, кто успешно проходит регистрацию на мобильных устройствах, оформляют заказ даже чаще десктопных. Исправление мобильной регистрации — самый быстрый способ увеличить количество заказов.



**RFM-сегментация.** Около 70% пользователей совершили одну покупку, около 20% — две, около 10% — лояльные с высокой частотой.



| Группа | Доля | Сегменты | Что делать |
| :--- | :---: | :--- | :--- |
| Одна покупка, недавние | 22% | 311–313 | Стимулировать повторный заказ |
| Одна покупка, средняя давность | 26% | 211–213 | Реактивационные кампании, промокоды с ограниченным сроком |
| Одна покупка, давно неактивные | 22% | 111–113 | Оценивать рентабельность перед активностями |
| Две покупки, недавние | 20% | 321–323 | Персональные предложения, накопительные бонусы |
| Лояльные (ядро — сегмент 333) | 10% (ядро — 2.8%) | 333 | Программа лояльности, эксклюзивные условия |



**K-Means кластеризация ресторанов.** Выделены четыре кластера:



| Кластер | Описание | Рекомендации |
| :---: | :--- | :--- |
| 1 | Непопулярные бюджетные, узкое меню | Программы лояльности для первых заказов, расширение меню, акции «вместе дешевле» |
| 2 | Популярные бюджетные, широкий ассортимент | Премиальные места в выдаче, рекламные интеграции, программы для постоянных клиентов |
| 3 | Непопулярные, средний чек выше среднего | Улучшение видимости в выдаче, спецпредложения для первых заказов |
| 4 | Непопулярные дорогие, очень узкое меню | Отдельная витрина, дегустационные сеты, акцент на качестве |



## Рекомендации



- **Мобильная регистрация** — приоритет: исправление даст быстрый рост конверсии.

- **Удержание пользователей** — система работы по сегментам: недавно привлечённым — скидки на второй заказ; средней давности — реактивационные кампании с промокодами; лояльных — эксклюзивные условия и программа лояльности.

- **Рестораны** — дифференцированный подход: кластеру 1 — помощь с меню и первыми клиентами; кластеру 2 — премиальные места в выдаче; кластеру 3 — улучшение видимости; кластеру 4 — отдельная витрина, ставка на качество и уникальность.

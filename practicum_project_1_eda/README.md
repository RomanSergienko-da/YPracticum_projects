Учебный проект: Изучение рынка заведений общественного питания Москвы

В учебном проекте (Яндекс Практикум) проведен исследовательский анализ рынка общественного питания Москвы, чтобы предложить инвесторам вариант подходящего места для открытия своего заведения.

Выполненные задачи:
- Знакомство с данными и предобработка: осуществлена проверка типов данных, обработка пропущенных значений, дубликатов и аномалий.
- Исследовательский анализ данных (EDA).
- Визуализация: построены информативные графики для наглядного представления структуры рынка и плотности заведений.
- Формулирование выводов: подготовлены рекомендации для инвесторов на основе результатов анализа.

Стек технологий и библиотеки:
- Python
- pandas, numpy, phik
